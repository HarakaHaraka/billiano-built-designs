# /assets/legacy/ — owner-collected imagery

Drop the images recovered from the old deploy (and any new project photography) into
this folder, then list each file in `frontend/public/data/hero.json` under `images`
to include it in the home-page hero rotation.

Recommended: JPG, ~1920px wide, under ~400KB each (compress before uploading so the
page stays fast). Suggested filenames already staged in hero.json:

- `hero-solar-roof.jpg` — solar PV on a terracotta tiled roof
- `hero-heat-pumps.jpg` — wall-mounted air-source heat pump units
- `hero-solar-terrace.jpg` — terraced homes with full-roof solar
- `hero-atrium.jpg` — daylight atrium / stack-ventilation architecture
